# 한국 풍력·기상 공개데이터 수집과 정리

풍력과 태양광 분석에 쓰려고 흩어져 있는 공개 자료를 받아 같은 형식으로 정리한 스크립트입니다. 같은 풍력 발전량이라도 거래량, 5분 계량값, 공식 이용률이 기관마다 기준이 달라서 이걸 맞추는 데 시간이 가장 많이 들었습니다. [`renewable-drought`](../renewable-drought)의 입력이 여기서 나옵니다.

| 스크립트 | 하는 일 | 출처 |
|---|---|---|
| `kpx_wind_hourly.py` | 시도별·전국 풍력 시간별 거래량과 5분 계량값(→시간) 패널 | 전력거래소, 공공데이터포털 15065269·15099452·15069372 |
| `epsis.py` | 연료원×시도 월별 설비·거래량·정산단가, SMP, 공식 이용률, 풍력 월별 시도 패널 | EPSIS 전력통계정보시스템 |
| `asos.py` | ASOS 지점 시간자료(기온·풍속·일사·운량 등) 병합 | 기상자료개방포털 |
| `era5.py` | 한반도 주변 0.25° 격자 10m·100m 바람 | ERA5 (Google ARCO-ERA5 공개 버킷) |
| `kma_buoy.py` | 해양기상부이 시간별 풍속·파고 | 기상청 API허브 |

## 정리하면서 맞춘 것들

- 시각은 모두 그 시간이 끝나는 시각 기준 `he = 1~24`로 통일했습니다. 5분 계량 자료는 시작 시각 기준이라 1을 더합니다.
- 2023년 12월부터 시도별 거래량이 '육지/제주'로만 나뉘어, 시도별 분석은 5분 계량값(2020~)을 씁니다.
- 2024년 6월부터 거래량에서 시장 밖 물량이 빠져 계량값보다 15~30% 작아집니다. 그 전 2019~2024년 중첩 구간에서는 두 값의 비율이 0.98~1.01이라, 전국 시계열은 2024년 6월에 계량값으로 바꿔 이어 붙였습니다.
- EPSIS 조회 화면은 표를 자바스크립트(`gridData.push`)로 내려주고 서버 쪽 `if` 분기가 섞여 있어, 문자열 비교로 분기를 먼저 풀고 표를 꺼냅니다.
- ASOS 흑산도는 1997년부터, 울진은 일사 관측이 없습니다. 운량은 2009년 이전 3시간 간격입니다.

## 실행 예

```bash
python kpx_wind_hourly.py raw/kpx out
python epsis.py raw/epsis out
python asos.py out/asos_hourly.csv.gz raw/asos/*.zip
python era5.py raw/era5 2015 2025
KMA_API_KEY=발급키 python kma_buoy.py download raw/buoy
python kma_buoy.py tidy raw/buoy out/kma_buoy_hourly.csv.gz
```

원자료와 결과 파일은 용량 때문에 저장소에 넣지 않았습니다. 파일명은 공공데이터포털에서 받은 이름 그대로 씁니다.
